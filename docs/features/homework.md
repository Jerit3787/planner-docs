# Homework and tasks

Use tasks to track assignments, readings, projects, and other work. Each task belongs to a subject and
can have a due date. You can leave the date unset if the task does not have a deadline.

## Add a task

From **Coursework → Tasks**, choose **Add**. Enter a title, choose a subject, and optionally set a due
date.

## Track progress

Use the progress control to set a task to 0%, 25%, 50%, 75%, or 100%. At 100%, the task is marked
**Completed**. Lower progress values remain in your upcoming work until the task is complete.

You can log a [focus session](pomodoro.md) against a task. Deleting the task does not delete focus
time already logged against it.
