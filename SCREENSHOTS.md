# Documentation screenshots

The help pages currently rely on written steps. Add an in-product screenshot only when it helps a
reader complete a task or understand a platform difference.

## Capture requirements

- Capture the current released Stutastic Planner app, not an older interface.
- Use synthetic names, classes, and study records.
- Capture the platform and screen size that the instructions describe. Add a second platform capture
  when its layout or steps materially differ.
- Check that text is readable and no personal information appears in the image.
- Save images under `docs/img/`, add useful alt text, and update this manifest when an image is added
  or replaced.

## Useful captures to consider

| Page | Possible capture |
|---|---|
| Home | Today and analytics overview on iPhone and iPad |
| Planner | Day, week, and month views; CSV timetable import; `.ics` export |
| Tasks | Task list and progress control |
| Academics | Semester setup, subjects, grades, and periods |
| Exams | Quiz and Final Exam details |
| Reminders | Native reminder settings on iOS or Android |
| Account | Guest choice, account options, and data backup/restore |

The exported App Store promotional images are store artwork. Use direct captures of the released app
for procedural help pages so that controls and labels match what readers see.
